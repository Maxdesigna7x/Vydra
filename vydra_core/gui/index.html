    Usage FAQ
    See the documented local inference FAQ (docs/GUI_FAQ.md). Predictions support biological review and require interpretation.
    What does Vydra predict?
    Vydra classifies protein sequences through a hierarchy: cellular or viral, then more specific categories. For structural phage proteins it predicts one of ten structural classes. It also provides reference context when available.
    Which input should I choose?
    Provide amino-acid sequences in FASTA format. Select a single file or a folder to discover FASTA files recursively. DNA and RNA must first be translated into proteins using an appropriate gene-prediction workflow; Vydra does not translate them.
    Can I analyze multiple samples?
    Yes. Keep separate FASTA files for each sample. Original files, folders, IDs, and headers are retained so results can be traced back to their source.
    Where should results be saved?
    Choose a new or empty folder outside the input folder. Existing results are not overwritten. Interrupted runs can reuse their existing folder with Resume run. The disk estimate includes an exact embedding checkpoint size and an approximate allowance for results and reports. Model downloads need additional space. Keep original inputs, complete predictions, manifests, run metadata, and the model/reference versions for reproducibility.
    Are my models local?
    Inference always runs on this computer. Vydra first checks local model files and its cache. Allow model downloads only permits downloading missing files; it does not send proteins to an online inference service. Disable it to require fully offline use. Desktop prepares the reference banks during setup. For the local browser installation, follow the model profile guide.
    Do I need a GPU?
    No. CPU runs the models and FAISS without CUDA. Automatic uses a compatible GPU when available and otherwise CPU. NVIDIA mode requires CUDA-enabled PyTorch. FAISS uses CUDA on supported Linux environments and CPU on Windows. Use Check installation to inspect the environment.
    What is batch size?
    The number of sequences embedded together. Automatic is the default. A smaller batch may reduce GPU memory use. Runtime also depends on protein lengths, device capacity, and other workloads.
    What happens to invalid or long sequences?
    The folder preprocessing records excluded sequences and reasons in secuencias_excluidas.csv; review it before interpreting results. Proteins longer than 2,048 amino acids use overlapping windows whose embeddings are averaged. Fragments can receive predictions but require cautious interpretation.
    What do progress and cancellation mean?
    Model loading and embedding generation show their current phase. During classification, progress reports actual processed protein counts. Checkpoints save every completed batch of chunks, including unfinished proteins, and each classified protein. The display shows completed and remaining proteins and chunks, the last checkpoint, and time without confirmed progress. After cancellation or interruption, select the run and click Resume run. Input, models and references must match. Saved chunks of a partially processed long protein are reused; only the interrupted batch may need recomputation. Closing the browser tab leaves the job running; stopping the server cancels its active job.
    What files will I receive?
    The local workflow writes complete CSV/JSONL predictions, a sequence manifest, exclusion records, summaries, and metadata. Generate inference report adds the interactive HTML report and its supporting exports. The HTML report is interactive and can be opened directly from completed runs.
    Which references support a phage prediction?
    Open a protein to inspect up to five nearest prototypes in its predicted class, including individual annotations, similarities and cluster IDs. Whole-cluster context remains separate; its representative can differ from the nearest reference. For proteins that reach M4, the report compares the top MLP and FAISS classes.
    What does hypothetical protein mean?
    The source annotation supplies no specific function. This text describes a reference, not a known function predicted for the query. Putative or probable descriptions are candidates, not evidence of experimental validation.
    Can I export the filtered proteins?
    Export filtered CSV or FASTA includes every matching row, including other pages. FASTA preserves original headers and residues. It requires a modern browser and an original-sequence snapshot; embeddings alone cannot provide residues.
    Where can I see processing time?
    The report header, metadata and tiempos.csv show whole-run inference and total processing time, including report generation when enabled.
    Are confidence, similarity, and taxonomy equivalent?
    No. Classifier confidence expresses model preference at a particular step. Embedding similarity compares a protein to a reference prototype and is not sequence identity. Genus, family, and host labels describe reference context; they do not certify the taxonomy or host of your query.
    Do percentages measure organism abundance?
    They count predicted proteins, not organisms, viral particles, or genomes. Interpret each percentage using its denominator. Conclusions about a genome, species, new virus, or experimental function require additional evidence.
    Does Vydra learn from my input?
    Inference uses prepared weights and references. Analyzing a FASTA does not retrain the models or automatically add proteins to the reference banks.

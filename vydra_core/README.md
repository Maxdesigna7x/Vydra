# Local runtime

This package contains Vydra’s supported CLI, local GUI, inference engine, model weights, reference artifacts, and interactive report generator. Start from the repository root with `./vydra gui` or `./vydra predict`.

See [CLI.md](CLI.md), [GUI.md](GUI.md), and the [main README](../README.md).

## Model profiles

The runtime supports ProstT5 and all three optional ESM‑2 profiles, with model-specific heads and FAISS reference vectors. [Profile setup and benchmark scope](../docs/MODEL_PROFILES.md).
